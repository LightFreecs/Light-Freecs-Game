# Menu fonts

Roboto Light / Medium / Bold / Black by Google, licensed under the Apache License 2.0
(https://www.apache.org/licenses/LICENSE-2.0). Copied from Unity's `com.unity.searcher` package, which ships them.

The design bench used Exo 2 (SIL OFL). To switch, drop the Exo 2 TTFs in this folder and assign them in
`Assets/_Project/Resources/MenuTheme.asset` (fonts section) — nothing else needs to change.
